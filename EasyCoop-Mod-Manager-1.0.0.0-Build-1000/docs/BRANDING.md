# EasyCoop Mod Manager – Markenauftritt

## Produktname

**EasyCoop Mod Manager**

Kurzbezeichnung: **EasyCoop**

Herausgeber: **EasyCoopClanTV**. Der Herausgebername ist nicht Bestandteil des Produktlogos.

## Logo

Das Logo verbindet eine Ordnerform als Symbol für Modverwaltung mit einer modernen Traktor-Silhouette als landwirtschaftlichen Bezug.

- `Assets/EasyCoop-Logo.png`: transparentes Masterlogo für Oberfläche, Web und Dokumentation
- `Assets/EasyCoop.ico`: Windows-Programmsymbol mit 16, 32, 48, 64, 128 und 256 Pixeln

Das Symbol darf zusammen mit dem ausgeschriebenen Produktnamen verwendet werden. Es sollte nicht verzerrt, eingefärbt oder mit fremden Herstellerlogos kombiniert werden.
